# Figma Shop Page

A small HTML and CSS practice project based on a shop page design. This project is being used to learn how to turn a visual layout into a structured webpage and style it with separate CSS files.

## Preview

Open `index.html` in a web browser to view the page.

No build tools, frameworks, or dependencies are required.

## Current Features

- Two-level navigation layout
- Contact information, logo, social links, and navigation buttons
- Shop hero section with breadcrumb text and hero image
- Price range input
- Color filter button layout
- Separate stylesheets for navigation, hero content, and page content

## Project Structure

```text
figma-shop-page/
├── index.html       # Main HTML page
├── nav.css          # Navigation and global styles
├── Hero.css         # Hero section styles
├── content.css      # Shop content and filter styles
├── README.md        # Project documentation
└── images/
    ├── Hero-img.png # Hero section image
    └── logo.png     # Site logo
```

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code or another editor.
3. Open `index.html` directly in a browser.

For a smoother development workflow, you can also use the VS Code **Live Server** extension and choose **Open with Live Server** from `index.html`.

## Learning Goals

- Practice semantic HTML page structure
- Learn how to split styles into focused CSS files
- Use Flexbox to arrange navigation and page sections
- Work with images and relative file paths
- Practice form controls such as range inputs and buttons
- Compare a browser implementation with a Figma design

## Next Steps

Possible improvements for continued practice:

- Add responsive styles for smaller screens
- Replace placeholder social links and icons with working links or icon assets
- Build the product grid in the right content area
- Add category filters and functional filter behavior with JavaScript
- Improve accessibility by using meaningful links, labels, and button behavior
- Replace fixed dimensions with more flexible responsive sizing
